# Устройство автомобиля для чайников

Если вы путаете свечи с форсунками, а радиатор с кондиционером — этот материал для вас.

### Три главные системы, которые надо знать
1.  **Двигатель (ДВС)**. Берет бензин, воздух и искру — делает **БДЫЩ-БДЫЩ** и машина едет.
2.  **Ходовая часть (подвеска)**. Чтобы вы не чувствовали попой каждый камешек на дороге.
3.  **Тормозная система**. Чтобы **БДЫЩ-БДЫЩ** вовремя прекратился.

### Куда что заливать?
- **Моторное масло**: Желтая/красная ручка со значком "лейка".
- **Омывайка**: Синяя крышка с фонтаном.
- **Тормозная жидкость**: Белый бачок, лучше не трогать без знаний.
- **Антифриз**: Большой бачок с розовой/зеленой жижей (НЕ ОТКРЫВАТЬ НА ГОРЯЧУЮ!).
