# Документы и оформление

Бюрократия, которая пугает больше всего. Этот раздел снимет тревогу через чек-листы.

### Азбука ДКП и ЭПТС

**Бумажный ПТС vs ЭПТС:**
- Бумажный: проверь, есть ли место для записи нового собственника.
- Электронный: нельзя потерять, запись вносит только инспектор.

**ДКП:** заполняется от руки, 3 экземпляра. Никогда не занижай сумму — налоговые риски и риск расторжения сделки.

**Цифровые сервисы:** настрой «Госуслуги.Авто» — показывай СТС на телефоне и записывайся в ГИБДД за 2 минуты.
